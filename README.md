# PlayHome

Interactive social party game platform built with React.

## Overview

PlayHome is a social gameplay platform focused on interactive group experiences, discussions, and party game mechanics.

The project includes:

- Web platform
- Published mobile application
- Multiplayer-inspired gameplay concepts
- Multi-language support

## Tech Stack

- React
- TypeScript
- Modern Frontend Architecture

## Features

- Interactive game flows
- Social gameplay mechanics
- Responsive UI
- Multi-language support
